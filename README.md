# École Esprit Global (مدرسة العقل العالمي) 🎓

منصة تعليمية تفاعلية أونلاين لتلاميذ المستوى الأول ابتدائي (Grade 1)، تجمع بين الأصالة والمعاصرة وتوفر تجربة تعليمية ممتعة ومريحة للأطفال.

## 🚀 المميزات والخصائص
- **واجهة ثنائية اللغة (عربي / إنجليزي)**:
  - اللغة العربية (افتراضية - RTL).
  - اللغة الإنجليزية (LTR).
  - تبديل سلس للواجهة مع حفظ الاختيار في `localStorage`.
- **مادة اللغة الفرنسية (French)**:
  - بطاقة المادة بالرمز `FR` (`🇫🇷`) ورابط `french_p1.html`.
  - محتوى دروس الفرنسية بالفرنسية (`lang="fr"`).
  - زر صوتي 🔊 لنطق الكلمات والأسئلة بنطق فرنسي فرنسي طبيعي (`fr-FR`) عبر Web Speech API.
- **عناوين المواد ديناميكية حسب لغة الواجهة**:
  - العربية: العربية / Maths: الرياضيات / الفرنسية: French / النشاط العلمي: Science.
- **محرك تمارين تفاعلي**:
  - أسئلة QCM مع تصحيح فوري وردود مشجعة.
  - نظام نجوم وتقييم (Star rating) وحفظ النقاط محلياً في `localStorage`.
  - بدون أي جمع بيانات شخصية من الأطفال وبدون أي كوكيز تتبع.
- **تصميم متجاوب بالكامل (Mobile-First)**:
  - ملاءمة تامة للهاتف (375px) والأجهزة اللوحية والحاسوب (1280px).

## 📁 هيكلة المشروع (Project Architecture)
```text
/
├── index.html            # الصفحة الرئيسية (عربي / إنجليزي عبر i18n)
├── about.html            # من نحن (الرؤية والرسالة)
├── primary1.html         # المستوى الأول – شبكة المواد الأربع
├── arabic_p1.html        # مادة: اللغة العربية
├── math_p1.html          # مادة: الرياضيات
├── french_p1.html        # مادة: اللغة الفرنسية (محتوى فرنسي + صوت fr-FR)
├── science_p1.html       # مادة: النشاط العلمي
├── contact.html          # نموذج التواصل
├── legal.html            # الشروط والخصوصية
├── i18n/
│   ├── ar.json           # نصوص الواجهة بالعربية
│   └── en.json           # نصوص الواجهة بالإنجليزية
├── css/
│   └── style.css         # ورقة الأنماط الموحدة وتنسيقات RTL/LTR
├── js/
│   ├── main.js           # محرك i18n والتبديل والقائمة المتجاوبة
│   └── exercises.js      # محرك التمارين والصوتيات الفرنسية fr-FR
├── data/
│   └── lessons.json      # محتوى الدروس (arabic, math, french, science)
└── assets/               # الصور والأيقونات والأصوات
```

## 🛠️ إضافة وتعديل الدروس
تتم إدارة جميع الدروس عبر ملف `data/lessons.json` بالهيكلة المعتمدة لكل مادة:
- `arabic`: دروس اللغة العربية
- `math`: دروس الرياضيات
- `french`: دروس اللغة الفرنسية (تشمل مصفوفة `words` والأسئلة التفاعلية مع دعم النطق 🔊 `fr-FR`)
- `science`: دروس النشاط العلمي
